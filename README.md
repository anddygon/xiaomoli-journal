# 小茉莉日记

在 iPhone 的 Safari 打开 [小茉莉日记](https://anddygon.github.io/xiaomoli-journal/)，可用「分享 → 添加到主屏幕」安装。两台手机都从平时使用的同一入口打开。

## 记录与备份

首页轻点「喂奶」会以母乳、双侧开始计时，可以换侧，也可以结束。轻点「睡眠」记入睡和醒来。补录奶粉、过去的喂奶或睡眠可用「补记 / 奶粉」，历史时间线也能按日补记。尿尿、便便、用药和益生菌有单独入口。时间线的记录操作提供编辑、删除，删除后的提示可撤销。

便便照片在手机上转为 JPEG，每张最多 350 KiB。断网可继续记录；首次打开请先联网，让离线资源加载完成。宝宝档案里的 JSON 备份包含照片、常用项目和出生资料。可在两部手机换机前分别导出并保存。旧版从原来的 Safari 或主屏幕入口升级时会自动迁入旧记录。

## 两位家长共用

一台手机只需配置一次。公开的网站仓库存放程序。家庭记录与照片在手机端加密后，保存到另一个**私有** GitHub 仓库。配对后两位家长各点自己的「本机记录人」，在日记前台或点「立即同步」时更新。

1. 仓库所有者为两台手机分别生成一枚 fine-grained personal access token。选 **Only select repositories**，只选私有数据仓库；**Repository permissions → Contents → Read and write**。授权界面可在「宝宝档案 → 家庭共享」打开。令牌直接填入对应手机。如令牌到期，在连接设置中更新即可。[GitHub 说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)
2. 第一台手机点「启用家庭同步 → 首次创建家庭」，填第一枚令牌。要上传以前记在这台手机上的内容，勾选「把这台手机原有的记录和照片并入家庭」。连接后用「查看恢复密钥」把密钥存入自己的密码管理器。
3. 第一台手机点「邀请另一位家长」，复制链接给对方，保持邀请页面打开。第二台手机从平时用的日记入口打开「启用家庭同步 → 使用邀请加入」，粘贴邀请链接和第二枚令牌。邀请有效期为 30 分钟，一次使用。手机之间无需互发令牌。两部手机都可通过同一仓库和恢复密钥重新连接。
4. 验收时先记一条尿尿，另一台手机应能看到；再用普通物品照片验收便便图片、删除与撤销。若同时离线编辑同一项，家庭共享会列出需要核对的两份修改。

私库保存 Git 版本历史。日记内删除会从两部手机的日常视图移除，之前提交过的加密版本会保留在私库历史中。令牌和恢复密钥须单独保管；导出的 JSON 是可直接读取的备份。连接速度取决于当前网络访问 github.io 和 api.github.com 的情况。
